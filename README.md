# 小狗桌宠

一个基于 Python + tkinter 的桌面宠物程序。黑色小狗在屏幕上自由游荡，点击小狗会生出鸵鸟蛋，蛋经过重力掉落、倒计时孵化后破壳而出新的小狗。支持配置文件和插件扩展。

## 功能特性

- 小狗在桌面最上层自由游荡，碰到屏幕边缘自动反弹
- 每只狗的移动速度和方向独立随机，有的慢悠悠有的飞快窜
- 左键点击任意小狗 -> 生出一颗鸵鸟蛋
- 鸵鸟蛋受重力影响掉落到屏幕底部
- 蛋经过 10 至 20 秒随机倒计时后开始孵化
- 孵化动画：蛋飞快旋转约 1.35 秒，随后小狗破蛋飞出，蛋消失
- 右键菜单：新增一颗蛋 / 退出
- 所有窗口无边框、透明背景、始终置顶
- 支持 `config.json` 自定义各项参数
- 支持 `plugins/` 目录插件扩展

## 环境要求

- Windows 操作系统
- Python 3.7 或更高版本
- Pillow 图形库（任意版本，程序自动兼容新旧 API）
- tkinter（Python 标准库，官方安装包默认包含）

## 快速开始

### 方式一：使用启动脚本（推荐）

1. 双击运行 `安装环境.bat`，自动检测并安装 Python 和 Pillow
2. 环境就绪后，双击运行 `启动.bat`

`启动.bat` 会自动检测 Python、Pillow、tkinter 是否可用，并在程序异常退出时显示详细错误信息。

### 方式二：手动运行

```bash
pip install Pillow
python main.py
```

## 操作说明

| 操作 | 效果 |
|------|------|
| 左键点击小狗 | 在小狗旁边生成一颗鸵鸟蛋 |
| 右键点击小狗或蛋 | 弹出菜单（新增一颗蛋 / 退出） |
| 等待 10-20 秒 | 蛋自动旋转孵化，破壳生出新狗 |

## 配置说明

所有可配置参数都在 `config.json` 中。如果该文件不存在，程序使用内置默认值。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `dog_width` | 140 | 小狗显示宽度（像素），高度按比例自动计算 |
| `egg_width` | 90 | 鸵鸟蛋显示宽度（像素） |
| `move_speed_min` | 0.6 | 小狗移动速度下限（像素/帧） |
| `move_speed_max` | 6.5 | 小狗移动速度上限（像素/帧） |
| `gravity` | 0.6 | 蛋的重力加速度（像素/帧平方） |
| `hatch_min_ms` | 10000 | 孵化最短倒计时（毫秒） |
| `hatch_max_ms` | 20000 | 孵化最长倒计时（毫秒） |
| `spin_ticks` | 45 | 孵化旋转持续帧数（45 x 30ms 约 1.35 秒） |
| `spin_frame_count` | 12 | 旋转一圈的帧数 |
| `animate_interval` | 30 | 动画帧间隔（毫秒），约 33fps |
| `change_dir_chance` | 0.02 | 小狗每帧随机变向的概率 |
| `max_dogs` | 50 | 屏幕上最多同时存在的小狗数量 |
| `max_eggs` | 30 | 屏幕上最多同时存在的蛋数量 |
| `transparent_color` | "magenta" | 窗口透明色（品红，不要改成小狗身上有的颜色） |
| `enable_plugins` | true | 是否启用插件系统 |

修改 `config.json` 后需重启程序生效。

## 插件系统

本项目支持插件扩展。将 Python 插件文件放入 `plugins/` 目录即可自动加载。

插件可以监听以下事件：小狗出生、蛋出生、蛋孵化、狗被点击、每帧更新、程序退出。

详细的插件开发教程和 API 文档请见：[plugins.md](plugins.md)

`plugins/` 目录中自带一个示例插件 `example_monitor.py`，在控制台打印各种事件信息，可作为编写插件的参考。

## 技术实现

- 使用 tkinter 的 `Toplevel` 窗口实现每只宠物独立窗口
- 通过 `overrideredirect` 去除窗口边框，`attributes("-topmost")` 实现置顶
- 通过 `attributes("-transparentcolor", "magenta")` 实现透明背景
- 图片素材预先合成到品红背景，使半透明边缘抗锯齿正常显示
- 使用 `after()` 方法实现约 33fps 的动画主循环
- 蛋的旋转通过预生成 12 帧旋转图片循环播放实现
- 破蛋飞出通过给新生小狗赋予初始向上速度和重力加速度实现
- 兼容 Pillow 9.1 以下版本（自动回退到 `Image.LANCZOS`）
- 插件系统通过 `importlib.util` 动态加载，钩子方法异常隔离不影响主程序
- 全局异常捕获，启动失败时弹出错误框并输出完整堆栈

## 常见问题

### 双击启动.bat 后闪退或显示错误码

`启动.bat` 已改进为不会闪退：程序异常退出时会暂停并显示完整的 Python 错误信息，同时保存到 `error_log.txt`。请根据错误信息排查，常见原因：

- **Pillow 未安装**：运行 `安装环境.bat` 或 `pip install Pillow`
- **tkinter 不可用**：重新安装官方 Python，安装时勾选 tcl/tk
- **素材缺失**：确认 `images/` 目录中有 `dogdogdog.png` 和 `鸵鸟蛋.webp`

### 另一台电脑上配置好环境还是报错

请确认：
1. Python 版本 >= 3.7（命令行执行 `python --version`）
2. Pillow 已安装（命令行执行 `python -c "import PIL; print(PIL.__version__)"`）
3. 用 `启动.bat` 启动，查看具体的错误输出
